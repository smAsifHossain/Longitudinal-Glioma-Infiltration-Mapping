# QC image release

QC images were not present in the uploaded public candidate and therefore are
not included in this archive.

Before publishing selected examples here, confirm that every panel:

1. contains no patient identifier, accession number, date, institution label,
   filename, or burned-in metadata;
2. is covered by the applicable consent, data-use agreement, and publication
   policy; and
3. uses a neutral filename such as `example_01.png` with no mapping back to a
   private case manifest.

Keep the complete case-level QC collection outside the public repository.
