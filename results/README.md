# Aggregate results

This directory contains only de-identified aggregate outputs.

- `models/<model>/`: five-fold metrics, pooled out-of-fold summaries,
  patient-bootstrap confidence intervals, and volume-bin figures.
- `biomarker/`: cross-model volume agreement, Bland-Altman statistics,
  bootstrap confidence intervals, and publication-ready figures.

Case-level CSV files, predictions, NIfTI volumes, checkpoints, and source
images are intentionally excluded from the public export.
